# SEO Audit Framework

## Priority Scoring

Score each issue from 1-5 for Impact, Effort, and Dependency.

Priority score:
- Base priority = Impact x (6 - Effort)
- Adjust -2 when blocked by external dependency
- Adjust +1 when issue affects top-converting pages

Interpretation:
- 18-25: Immediate quick win or critical fix
- 12-17: Plan in next sprint
- 7-11: Queue after fundamentals
- 1-6: Low priority

## Issue Buckets

1. Technical
- Crawl/index blockers, canonical conflicts, broken internal links, poor Core Web Vitals on key templates.

2. On-page and Content
- Search intent mismatch, weak titles/meta descriptions, thin pages, weak heading hierarchy, missing schema where useful.

3. Internal Linking and Architecture
- Orphan pages, shallow topical clusters, weak contextual anchors, over-deep click paths to money pages.

4. Authority and Trust
- Weak backlink profile relative to competitors, missing trust pages, weak E-E-A-T signals for YMYL topics.

5. Entity and Social Alignment
- Inconsistent brand name/description/contact details across website and social profiles.
- Missing link consistency between social bios and canonical website pages.

## KPI Mapping

Map each recommendation to one primary KPI and one secondary KPI.

Primary KPI options:
- Non-brand organic clicks
- Impressions for target query clusters
- Avg position of priority URLs
- CTR on ranking pages
- Qualified organic conversions

Secondary KPI options:
- Indexed pages quality ratio
- Internal link count to priority pages
- Branded query growth
- Returning visitor rate from organic

## Clarifying Questions Template

Ask only what is required to make decisions:
1. Which pages drive revenue or leads today?
2. Which country/language is the primary SEO target?
3. What CMS/platform is used?
4. Which competitors currently outrank you for target terms?
5. Are there recent redesigns, migrations, or URL changes?

If answers are unavailable, proceed with assumptions and call them out explicitly.
